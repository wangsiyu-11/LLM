# Practice02

## 文件列表

- `chat-stream-tool-getDate.py` — 工具 getDate：获取当前电脑日期时间（调用本地 date 命令）
- `chat-stream-tool-leapyear.py` — 工具 getDate + isLeapYear：判断闰年
- `chat-stream-tool-fileOps.py` — 10个文件操作工具：查看/创建/编辑/删除/重命名文件和目录
- `architecture.mmd` — 架构图（Mermaid 格式，可粘贴到 https://mermaid.live 查看）

## 运行

```bash
python chat-stream-tool-fileOps.py
```

需要在代码中填入硅基流动的 API Key。

## 文件操作工具列表

1. getcwd — 获取当前工作目录
2. listdir — 列出目录下所有文件和子目录
3. filetype — 获取文件类型
4. readfile — 读取纯文本文件内容
5. createfile — 创建新文件
6. editfile — 编辑文件内容
7. mkdir — 创建新目录
8. rmdir — 删除非空目录
9. rmfile — 删除文件
10. rename — 重命名文件或目录
